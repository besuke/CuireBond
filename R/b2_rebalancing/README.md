# b2_rebalancing：ポートフォリオ入れ替え提案（Phase 2）［未実装］

ファンド別の戦略・制約（B1）、現在の保有、オファー（A1）を使って、売りと買いを組み合わせた入れ替え案を作る。
数値計算・最適化・制約判定はRで行い、提案理由の文章化はClaudeエージェントが担う。

## 対象とする入れ替え

- 円債と外貨債の間の入れ替え
- 国債間の入れ替え
- 短期化／長期化
- 国債からクレジット債への入れ替え

## 予定する入力

- 現在の保有：Aladdin APIから取得（API仕様・認証は未提示。推測で実装しない）
- 戦略・制約：B1の共通形式
- オファー：A1の出力（スプレッド・信用情報付き）、売却可能価格
- 現金、為替ヘッジ、取引費用
- 金利シナリオ：クオンツが指定するカーブやモデル。
  「信用スプレッドを一定とする」分析は一つのシナリオ条件として明記し、信用リスク枠の計測とは分けて扱う

## 予定する出力

- 売却候補・購入候補と数量
- 入れ替え前後の比較：通貨配分、利回り・ASW、デュレーション・DV01、信用リスク、費用
- 制約判定（各制約の適合・違反と余裕）
- 信用上の論点（A3の整理結果を参照）と提案理由

## 未確定

Aladdin APIの保有取得仕様、最適化の目的関数、取引費用のモデル、信用リスク枠の計測方法、シナリオの入力形式。
