# A2_valuation：時価適正性の検証（Phase 1）［未実装］

前月のBloomberg時価から評価パラメータを逆算し、当月の市場データで当社Fair Valueを計算する。
ICE／DIR時価、オファー価格との乖離を抽出する。前月価格をそのまま当月のFair Valueとしない。

## 予定する入力

- 前月のBloomberg時価（価格の種別、評価日・受渡日、取得時点）
- 前月・当月の市場データ（カーブの元となる気配。出典を残す）
- 当月のICE時価、DIR時価、オファー価格（A1の出力）
- 銘柄属性（`R/Z0_utility/attributes.R` の取得関数）
- 乖離の閾値

## 予定する出力

- 銘柄ごとの当社Fair Value、逆算したパラメータ、使用したカーブと出典
- ICE／DIR時価・オファー価格との乖離と、閾値を超えた銘柄の一覧

## 既存関数で実現できる経路（候補。採用は未確定）

- ASW：`compute_asset_swap_ISO()` で逆算 → `asset_swap_fair_price()` で当月の価格へ
- Zスプレッド：`GaussQuant::bond_zspread_GQL()` で逆算 → `GaussQuant::bond_npv_with_zspread_GQL()` で当月へ

## 未確定（実装前に確認）

逆算するパラメータ、基準カーブと規約、銘柄別か区分別か、前月時価がない銘柄の扱い、
閾値の単位と水準、ICE・DIR時価の価格定義（クリーン／ダーティ、評価日・受渡日）。
比較時は価格単位・通貨・クリーン／ダーティ・評価日・受渡日をそろえる。
