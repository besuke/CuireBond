# A3_credit_reports：クレジットレポート読込・紐づけ（Phase 1）［未実装］

証券会社のクレジット・格付けレポートを、ISINまたは発行体IDで銘柄と関連付ける。
読解・要約はClaudeエージェントが行うことを想定し、紐づけと記録はRで行う。

## 予定する入力

- クレジットレポート（入手元・形式は未定）
- 銘柄と発行体IDの対応（体系は未定）
- オファー銘柄（A1の出力）

## 予定する出力

- 銘柄・発行体とレポートの対応表：レポート名、証券会社、公表日、原文URL
- 格付け、見通し、信用上の論点の整理（Claudeエージェントによる要約。参照元と日付を付ける）
- オファーExcelから開けるリンク。複数資料がある場合は別シートの一覧と要約

## 方針

- URLがない場合は空欄とし、推測で生成しない
- 要約は参照元（レポート名・証券会社・公表日）と結び付けて保持する
- 数値の判定や計算はAIに任せず、Rで行う
