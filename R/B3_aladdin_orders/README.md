# B3_aladdin_orders：Aladdin APIによる発注（Phase 2）［未実装］

B2の入れ替え提案から発注案を作り、所定の承認を経た注文だけをAladdinの発注APIで送信する。

## 予定する処理

- B2の提案から発注案を作成する。売却、購入、必要な為替取引を同じ入れ替え案件として管理する
- ファンドマネジャー等の所定の承認を経た注文内容だけをAPIで送信する
- 発注ID、受付結果、約定、一部約定、取消などの状態を取得・管理する
- 二重送信を防止し、片側だけ約定した場合を管理する
- 承認・送信・状態変化の操作履歴を残す

## 予定する入力

- B2の入れ替え提案
- 承認の記録（承認者、日時、承認した内容）
- Aladdin発注APIの接続設定（認証情報はリポジトリに含めない）

## 予定する出力

- 発注案、送信記録、発注ID、状態の履歴
- 一部約定・片側約定などの要対応一覧

## 方針

- APIの仕様、認証、権限、承認フローは後で提示される。エンドポイントを推測して実装しない
- 承認を経ない送信、テスト環境以外での試験送信は行わない

## 未確定

発注APIの仕様、認証・権限、承認フロー、二重送信を判定するキー、状態の定義。
