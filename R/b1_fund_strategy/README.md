# b1_fund_strategy：ファンド戦略・制約条件の読込（Phase 2）［未実装］

ファンドマネジャーが設定するファンド別の戦略と制約を、共通形式に変換して検証する。
読み込んだ戦略・制約は b2_rebalancing（入れ替え提案）で使う。

## 扱う戦略・制約（例）

通貨配分、為替ヘッジ方針、年限、デュレーション、格付け、信用リスク枠、発行体などの集中制限、
流動性、投資可能商品、売買単位、現金制約、取引コスト。

## 予定する入力

- ファンド別の戦略・制約の設定ファイル（形式は未定）

## 予定する出力

- 共通形式の戦略・制約（ファンド、項目、値、単位、適用日、版）
- 検証結果：単位、適用日、版、必須項目の不足・不整合

## 未確定

設定ファイルの形式、項目の一覧と単位、版管理の方法、承認の要否。
