# A4_daily_report：日次レポート・目玉オファー（Phase 1）［未実装］

当日のクレジットレポートとオファーを集約し、日次サマリーと目玉オファーを作る。

## 予定する処理

- 当日のクレジットレポートを集約する（A3の出力）
- 前回のオファーシートとの比較で、新規オファー・変更オファーを抽出する
- 数値差分の判定（価格・スプレッドの変化、閾値判定）はRで行う
- Claudeエージェントが信用情報と計算結果を使い、日次サマリーと目玉オファーの選定理由を文章化する

## 予定する入力

- 当日と前回のオファーシート結果（A1の出力）
- 当日のクレジットレポートの整理結果（A3の出力）
- 時価乖離の一覧（A2の出力）
- 目玉オファーの選定基準

## 予定する出力

- 新規・変更オファーの一覧（比較対象の時点を明記）
- 日次サマリー、目玉オファーと選定理由（参照元へのリンク付き）
- 記録：比較対象時点、選定基準、参照元

## 未確定

目玉オファーの選定基準、「変更」とみなす差分の閾値、出力形式。
